Lead Perfection Calendar Test

Test real-time availability from Lead Perfection API

⚠️ Setup Required

The Lead Perfection API blocks direct browser requests (CORS). You need to set up a Make.com webhook to proxy the API calls.

Click for Make.com Setup Instructions
  1. Create a new Make.com scenario
  2. Add Webhooks → Custom webhook as trigger
  3. Add HTTP → Make a request module:
    • URL: https://api.leadperfection.com/token
    • Method: POST
    • Body type: application/x-www-form-urlencoded
    • Fields: grant_type=password, username=Peakleads, password=Peakleasds#1, clientid=ry32a, appkey=AED0AE62-ACF3-447A-941D-683AEC87C0DD
  4. Add another HTTP → Make a request module:
    • URL: https://api.leadperfection.com/api/Leads/GetLeadsForwardLook
    • Method: POST
    • Headers: Authorization = Bearer {{access_token from step 3}}
    • Body type: application/x-www-form-urlencoded
    • Fields: branchid=, productid=, zip={{zip from webhook}}
  5. Add Webhooks → Webhook response module:
    • Status: 200
    • Body: {{data from step 4}}
  6. Copy the webhook URL and paste it into the code at the top:
    const MAKE_WEBHOOK_URL = 'your-webhook-url-here';
